## API 키 발급

- **가입 URL**: [https://www.data.go.kr](https://www.data.go.kr)
- **절차**: 회원가입 → 소상공인시장진흥공단 상가(상권)정보 Open API 활용신청 → 승인 후 인증키 확인
- **환경 변수**: `KPUBDATA_SEMAS_API_KEY`

## 환경 변수

```bash
export KPUBDATA_SEMAS_API_KEY="발급받은키"
```
